# Stranger review, round 45

Walk: README only, then CLI and HTTP on a copy (port 7795; see 1). No browser tool installed, so views were checked by `curl` and CLI only (status codes, JSON, text output).

1. **The README's test port can already be taken, and the failure is silent.** I started the copy with `LANEBOARD_PORT=7790` as instructed. It died with `EADDRINUSE` in a log I had sent to a file. My next `curl localhost:7790` got 200 from another board already on that port, with real sessions and a `demo` run. I read that data as my copy's until `ss -ltn` showed a different pid. The README does warn that on a taken port "the board already there answers", but from the curl side nothing shows it. Suggest: a one-line stderr message ("port 7790 taken, not started"), and the README example checks `ss -ltn` first.
2. **`laneboard pause --all` / `resume --all` / `paused` ignore `LANEBOARD_URL` and the copy's state dir.** With the CLI pointed at my copy, `pause --all` wrote `~/.local/state/laneboard/paused/ALL`, the real machine's sentinel, which pauses every real session. I resumed it right away. The README says the copy touches neither the config nor the state dir, and that `pause` "works with the server down", so a stranger following both pauses their real board. Suggest: honour `LANEBOARD_STATE_DIR` in these CLI commands, or say in the isolation paragraph that offline commands (`pause`, `resume`, `audit`, `run` without `--post`) use the real state dir.
3. **`laneboard launch <lane> --plan docs/plans/<lane>.md`, as printed in the README, fails:** `laneboard: args.repo is required` (no repo configured). `--help` shows `[--repo <repo>]` as optional. The message should say "no repo given and none configured: pass --repo or set `repos`", with a hint at `laneboard dirs`.
4. `peek nothere` says `unknown session`, `retire nothere` says `no launched lane nothere`. Neither points at `laneboard ls`. Minor.
5. **API names are not guessable and the 404 body gives no hint.** `/api/health`, `/api/sessions`, `/api/box`, `/api/inbox`, `/api/audit`, `/api/approvals`, `/api/version`, `/api/diff` all return 404 (about 40 bytes). The views map to `#/…` routes, but no doc lists the read endpoints in one place (runs.md and map.md list theirs). Suggest an endpoint table or an `/api` index.
6. **`laneboard morning` "What it cost"** puts three full session UUIDs into the SESSIONS column for the ended-sessions row. The line goes past 150 columns and shows nothing useful. Suggest a count ("3 sessions").
7. **`laneboard credit`** prints `Credit   5h   -   7d   -` and `sampler: 0 samples, last never` with no hint of what turns the sampler on. Dead end for a newcomer.
8. The README CLI list leaves out `laneboard feed` (in `--help`, and in docs/map.md).
