# Paths no unattended round of a cockpit BUILD night may change. A round that touches one is reverted
# whole and the owner is told (run.sh `fenced_hits`). Bash globs, one per line, matched against
# repo-relative paths; `*` also matches `/`. Committed, uncommitted and untracked changes all count.
#
# Three kinds of line:
#   <glob>    fenced: any change reverts the round.
#   ~<glob>   small edits only: all `~` files of one round together may change at most SPEC_TYPO_LINES
#             lines (default 6), and no new file; for typo-level spec fixes, each noted in PROGRESS.md.
#   (built in) package.json / package-lock.json may change only to add `@playwright/test` (devDependency,
#             with the lock entries it brings) and the `test:cockpit` script (run.sh `pkg_guard`).
#
# Something a build needs in a fenced file is written as a patch under
# docs/plans/cockpit/build/patches/<task>-<topic>.diff and named under `## For the owner`; an attended
# session reviews and applies it.
